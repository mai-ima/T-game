## 2. 領域別の知見と自作ゲームへの適用案

### A. 動機づけ

**知見**
- 【事実】自己決定理論は、自律性・有能感・関係性の3欲求の充足が内発的動機と well-being を高めるとする [3]。ゲームでも3欲求の充足が楽しさと再プレイ意欲を独立に予測した [1][2]。
- 【事実】ゲーマー動機モデルは12動機（破壊・興奮・競争・コミュニティ・挑戦・戦略・完遂・パワー・空想・物語・デザイン・発見）を6組に整理する [17][18][19]。モデルの理論的位置づけには批判もある [18]。
- 【事実】フロー（挑戦と能力の釣り合い等）は、Chen がプレイヤー自身の選択で難易度が動く設計を提案 [21]。フロー条件は全部が必須ではないとされる [21の二次言及]。
- 【事実】没入は段階的（没頭→没入→完全没入）で、フローとは別概念として扱われる [20]。
- 期待価値理論・達成目標理論は今回出典を取得できず（§5）。

**適用案**
| 場面 | 仕組み |
|---|---|
| 自律性 | 章の中で「どの順で動くか／誰に先に話すか」を選べるが、**どの選択も物語が進む**。選択肢ごとに理由が見える（「なぜそう思う」）。運転・指令のミニゲームは手動／補助の度合いを自分で選べる。 |
| 有能感 | 運転・指令の採点は「減点」より「できたこと」を先に提示。失敗後に原因を1行で示し、再挑戦を即可能に。 |
| 関係性 | 同僚・上司・利用者との関係値は「好感度」でなく、過去の約束・借りの記憶として台詞に反映（§D/Fと連動）。 |
| 動機の多様性 | 運転（挑戦）、経営（戦略）、物語、駅の観察（発見）、車庫の整備（完遂・デザイン）を並行して置き、**どれか1つに偏らなくても進める**。 |
| フロー | ミニゲームは3段階（見習い／一人前／熟練）をプレイヤーが途中で切替可能。連続失敗時に「補助を増やしますか？」と提案（強制しない。Chen の選択型調整 [21]）。 |

### B. 感情と物語

**知見**
- 【事実】物語への没入（transportation）は注意・イメージ・感情の統合で、信念の変化と関連する [4]。ただし媒介効果が一貫しない研究もあり、イメージ中心の改訂モデルも提案されている [4][5]。
- 【事実】サスペンスは、好意を持つ主人公と悪い結末の確率が高いほど強まる（Zillmann の気質理論）。不確実性が中核だが、結末を知っても感じる「変則的サスペンス」の議論もある [13][14]。
- 【事実】特定可能な犠牲者効果: 個人としての被害者には同情するが、統計の被害者には同情が湧きにくい。統計を併記すると個人への同情も下がる [11]。ただし熟慮が同情を下げるという因果は研究間で一致しない [12]。
- 【事実】ピーク・エンド: 経験の評価は最も強い瞬間と終わりに強く影響され、持続時間は軽視される（持続時間の無視） [8][9]。メタ分析で強く支持（r≈0.58、174標本）されるが数値は二次要約 [10]。明確な始まりと終わりのある経験に当てはまる [8の二次言及]。
- 【事実】「泣ける」「感動」は快楽（楽しい）とは別の「鑑賞（appreciation）」＝意味ある経験として説明できる [47]。悲しい作品でも満足が得られる [47]。
- 【事実】ノスタルジアは人との絆を描き、物語は多くが肯定的・救済の筋を持つ。孤独や否定的気分が引き金になり、社会的つながり・自己肯定を高める [55]。
- 【事実】パラソーシャル関係は社会的欠乏の代用というより社会生活の延長として捉えられる [48][49]。
- 【事実】「悪は善より強い」: 悪い出来事のほうが影響が大きいとする総説 [58][59]（普遍ではない [59]）。

**適用案**
| 場面 | 仕組み |
|---|---|
| 人物の描き方（犠牲者効果） | 事故・遅延の影響を「乗客1,200人」でなく、**名前・癖・小さな約束を持つ1人**（例: 受験に向かう高校生、孫に会いに行く老人）として先に出し、その後に規模を示す。統計だけの提示は避ける。 |
| 章末の引き | 章末は「問いを1つ残して感情は決着させる」。感情を未解決にし続けない（§D）。 |
| ピーク・エンド | 各章に**1つの感情のピーク**（山場）を設計し、**最後の1シーン**は必ず余韻（小さな救い、日常の描写）で締める。シーズン最終章は特に終わり方を丁寧に。途中が長くても、ピークと終わりが良ければ全体評価は良くなる、という前提で配分。 |
| サスペンス | 「誰かが死ぬ」ではなく、**運行・信頼・約束が守られるか**で緊張を作る。好意を持てる人物（先に魅力を描く）＋不確実な結果＋制限時間。 |
| 緩急・コントラスト | 緊張章の次は穏やかな日常章（駅弁の話、新人の笑い）を置く。コントラストで両方が強まる、という【推測】。 |
| 泣ける仕組み | 「悲しみ」より「意味」: 長年の努力・世代を超えた継承・最後の一礼など、**価値観が確認される瞬間**を終盤に置く。 |
| ノスタルジー | 古い車両の引退、廃線、駅舎の取り壊しなど「時代の終わり」を、過去の人間関係の回想と結びつけて描く。 |
| パラソーシャル | 主要NPCに固有の口調・日常（朝の挨拶、メモ）を持たせ、プレイヤーが不在の間も彼らの生活が進んでいることを示す。 |
| 悪の強さ | 悪いニュースは強く響くため、**1章に重い出来事を詰め込みすぎない**。良い出来事も同じ丁寧さで描く。 |

### C. 意思決定

**知見**
- 【事実】損失回避は大きな損失では確認されやすいが、小さな損失での一般性には論争がある [22][23][24]。**「損は得の約2倍」を普遍法則として扱わない。**
- 【事実】予期後悔は、決定が重要で難しく、選ばなかった結果も早く分かると予想されるときに強く働く [34]。
- 【事実】サンクコスト効果・現状維持バイアスは多数の実験で報告 [50][51]。デフォルトが選択を強く左右する（二次言及）。
- 【事実】選択過多: 有名なジャム研究 [27] だが、メタ分析では平均効果はほぼゼロでばらつきが大きい [25]。調整要因（選択肢の複雑さ、課題の難しさ、選好の不確かさ、目標）を考慮すると効果が出るとの反論もある [26]。
- 【事実】認知的不協和: 理論は長く影響したが、強制承諾パラダイムは多施設追試で頑健性に疑問 [35][36]。
- 【事実】二重過程理論は広く使われるが、「2系統」の厳密な区別には批判がある [31]。道徳判断でも、直観的反応と熟慮の競合が示唆された [30]。
- 【事実】道徳基盤理論は多元的な道徳の次元を説くが、多元性の主張自体への批判もある [28][29]。
- 【事実】権威への服従: Burger の追試は150Vまでで約7割が継続（元の83%と有意差なし）。ただし設計への批判あり [52]。

**適用案**
| 場面 | 仕組み |
|---|---|
| ジレンマ設計 | 「正解のない二択」ではなく、**両方に守るべき価値がある**（安全 vs 約束、現場 vs 本社）。選ぶ側・選ばなかった側の両方の理由を事前に提示し、後でその両方の結果が見える（予期後悔を適度に働かせる）。 |
| 損失の見せ方 | 失うものは**小さな数値でなく具体物**（失う信頼、遅れる便、引退する車両）にする。「−10pt」のような抽象的損失に頼らない。 |
| サンクコスト | 長く育てた路線・車両・関係への愛着を物語にする。「やめる」選択を重くし、**やめる自由も常に残す**（やめた後の道も物語になる）。 |
| 選択肢の数 | 重要局面は**2〜4個**に絞る。理由は選択過多の効果が条件付きだから [25][26]。複雑な課題・好みが不明確なときは特に絞る。 |
| デフォルト | 設定のデフォルトは「プレイヤーに有利な安全側（字幕ON、自動保存、強制しない補助）」にし、操作を誘導する目的では使わない。 |
| 時間圧力 | 緊急時は**カウントダウン付きの直観的選択**（2〜3択）、平時は**無制限の熟慮**。時間圧力は「プレイヤーが切れる」オプション（アクセシビリティ）を用意。緊急での決定は後で振り返りシーンを置き、結果への文脈を与える。 |
| 道徳の次元 | 道徳基盤（ケア・公正・忠誠・権威・神聖…）を人物ごとに異なる主軸にして、**価値観の衝突**を描く。ただし理論自体に批判があるため分類ラベルは作中に出さない。 |
| 権威 | 上司の指示に従うか否かの場面を入れ、従った場合・逆らった場合のどちらも現実的な結果にする（罰ゲームにしない）。 |
| 認知的不協和 | 使うなら補助的に: 自分が下した選択を後の章で別の視点から見せ、「あの判断は正しかったか」を考えさせる。**不協和を意図的に作って態度を操作することはしない。** |

### D. 好奇心・期待

**知見**
- 【事実】好奇心は「知りたい情報との間に知識のギャップがある」と気づくときに生じる。先行知識が必要 [6][7]。
- 【事実】ツァイガルニク効果（中断した課題を覚えている）は**一般には成立しない**。メタ分析では、再開傾向（オフシャンキナ効果）は一般的だが、ツァイガルニク効果の普遍性は支持されにくい [33]。
- 【事実】ドーパミンは報酬そのものではなく、予測との差（予測誤差）を符号化するとされ、学習に関係する [32]。
- 可変報酬: 依存的利用を招き得る。**本計画では使わない**（§3）。

**適用案**
| 場面 | 仕組み |
|---|---|
| 章末の引き | 「次に何が起こるか」でなく**「特定の問いが1つある」**状態で終える（例: 無線で聞こえた声は誰か）。**プレイヤーが知っている手がかり（先行知識）を先に置く**ことでギャップを感じさせる。ツァイガルニク効果は根拠が弱いので、「未完了だから忘れない」とは頼らない。 |
| 再開しやすさ | 中断後に再開する際、直前の状況と次の一手を**1画面で復習**（オフシャンキナ的な再開傾向は支援するが強要しない）。 |
| 伏線（予測誤差） | 伏線は**2段階**: ①プレイヤーに予測を立てさせる手がかり、②予測と**少しだけ違う**真相（完全な意外より、納得できる意外）。その真相が過去の手がかりと整合し、振り返ると見えるように置く。 |
| 好奇心の誘導 | 発見要素（駅の隅の掲示、古い写真）は、「ここに何かある」と感じさせる断片を先に出し、深掘りは任意にする。 |
| 予測誤差の使い方 | 完全に予想通り／完全に予想外の連続は飽きる、という【推測】。成功の見込みが高い場面で小さな想定外（遅延の原因が別だった等）を入れる。 |

### E. 学習と習熟

**知見**
- 【事実】失敗は嫌なものだが、ゲームでは失敗の痛みが快楽を可能にする（失敗のパラドックス）[53]。
- 【事実】juice（過剰ではない視聴覚フィードバック）は満足感を高めるとされるが、やり過ぎへの反論もある [56][57]。実験的な効果量は今回未確認。
- 【事実】MDA: 設計者は仕組みから考えるが、プレイヤーは先に感情（美学）を体験する [60]。

**適用案**
| 場面 | 仕組み |
|---|---|
| チュートリアル | 本編の状況の中で1回に1要素。**やってみる→結果を見る→言語化**の順。説明テキストは最小限（§G）。 |
| 失敗 | 失敗直後に原因を絞って提示、即リトライ、**ペナルティで長時間を失わない**。連続失敗時は補助を提案（強制しない）。 |
| ゲームフィール | ブレーキ操作・ドア扱い・信号確認に、**音と小さな動き**（ドット絵の揺れ、ベル、車輪音）で手応えを付ける。ただしジュースは操作の意味を支える範囲に限る。 |
| 設計の確認 | MDAに沿い、「どの感情を狙うか（美学）」を先に決め、仕組みを後から決める。 |

### F. 社会心理

**知見**
- 【事実】社会的浸透理論: 関係は自己開示の深まりで進み、開示が報われれば深まる。のちに循環的・往復的に改訂された [45]。
- 【事実】信頼は「脆弱さを受け入れる意志」であり、相手の能力・善意・誠実さの認知に支えられる [46]。
- 【事実】同調・服従の古典研究は追試や批判を含む。服従は条件次第で今も生じ得る [52]。
- 社会的比較は今回出典未取得（§5）。

**適用案**
| 場面 | 仕組み |
|---|---|
| 関係の発展 | NPCは雑談→仕事の悩み→過去の失敗→価値観の順に自己開示し、**プレイヤーが相手の話を聞く選択**をすると次の層が開く。ただし「聞かなくても進行できる」。 |
| 信頼の形成と毀損 | 信頼を能力・善意・誠実さの3軸で扱う。約束を破る・報告を隠す・手柄を取る等は**毀損としてNPCの態度に反映**し、**修復の道（謝罪・行動）**も用意する。 |
| 集団力学 | 駅や車庫のチームで、意見が割れる会議シーンを置く。**少数意見が正しい／間違っている両方のケース**を描く。 |
| 社会的比較 | 他社員との比較ランキングは使わない（出典未取得、かつ不安を生みやすいという【推測】）。必要なら「過去の自分」との比較。 |

### G. 認知負荷・UI

**知見**
- 【事実】作業記憶には厳しい容量制限があり、実質は約4チャンク程度と考える立場が有力（二次言及）。認知負荷理論は内在・外在・関連の負荷に分ける [37][38]。
- 【事実】近接はゲシュタルト原則で強力な分類手がかり [61]。
- 【事実】フィッツの法則（標的は大きく近く）、ヒックの法則（選択肢が増えると判断時間が増える）は一般的UX指針として使われるが、今回の出典は二次解説 [62]。

**適用案**
| 場面 | 仕組み |
|---|---|
| 画面情報 | 1画面の重要情報を**4つ前後**のまとまり（チャンク）に。運転画面は「速度・信号・次駅・時刻」など役割で近接配置。 |
| 外在負荷 | 同時に読む文章と操作が重ならないようにする（運転中は台詞を短く、読み込みは後で振り返れる）。 |
| タップ領域 | モバイルUIは主要ボタンを親指圏に大きく配置（フィッツ）。緊急操作ほど大きく。 |
| 選択肢の見せ方 | 5つ以上は階層化。重要な場面は2〜4（§C）。 |
| 文章 | 1文を短く、1画面あたりの文字量を抑える、ルビ・用語の脚注。専門用語は初出で1行説明。 |

### H. 職場ドラマ特有

**知見**
- 【事実】心理的安全性（対人リスクを取れるという共有信念）は、チームの学習行動と関連し、業績に媒介された [16]。
- 【事実】燃え尽きは職場の6領域（仕事量・裁量・報酬・共同体・公正・価値観）の不一致で説明される [39]。仕事の要求は消耗、資源の欠如は離脱に関連する [40]。
- 【事実】職業興味の6類型（RIASEC）は広く使われる [63]。キャリア構築理論などは今回未取得（§5）。

**適用案**
| 場面 | 仕組み |
|---|---|
| 心理的安全性 | 職場ごとに「ミスを報告しやすいか」を差別化。**報告したら責められる職場／学びに変える職場**を対比し、安全な報告文化が事故を防ぐ過程を描く。 |
| 燃え尽き | 主要人物の1人が6領域のどこかで歪み、徐々に離脱する過程を描く。プレイヤーの経営判断（人員・休暇・評価）が**資源**として作用。 |
| 異動・キャリア | 社員異動は適性（RIASEC的に「人と関わる／機械／管理」）と本人の価値観の両面で決まるようにし、**正解は1つにしない**。 |
| 経営 | 数字の改善と人の疲弊のトレードオフを可視化（疲労・不満の指標）。ただし指標でなく、人物の台詞・表情で伝える。 |

## 3. 倫理面の注意（やってはいけない使い方）

出典: [41][42][43][44][58]、およびプレイヤーの自律を尊重する立場（SDT [3]）。

1. **可変報酬・ガチャ的な間欠強化**で来訪を誘導しない（依存を狙う設計）。報酬は予告可能・再現可能に。
2. **ストリーク（連続ログイン）や期間限定で損失回避を煽らない**。「今日やらないと失う」を作らない。不在時も何も失わない。
3. **サンクコスト・現状維持を悪用して離脱を妨げない**（解約・終了の難しさ）。やめる導線を常に明確に。
4. **ダークパターン**（隠れた誘導、プレッシャー、偽の希少性、感情を使った引き留め）を使わない [41][42]。
5. **特定可能な犠牲者効果で課金や広告に誘導しない**。物語内の共感のみ。
6. **意図的に作った不協和・後悔でプレイヤーの態度や行動を操作しない**。内省の素材に留める。
7. **ピーク・エンドを利用して、中盤の不快を隠す設計をしない**（不満を隠す目的での終わり良ければ、は不可）。
8. **社会的比較・ランキング・同調圧力**で行動を誘導しない。
9. **長時間プレイの助長をしない**。休憩提案や自然な中断点を用意する。画面時間と well-being の関係は一様でなく、適度が最善とされる [44]（効果は小さい。因果は断定しない）。
10. **時間圧力は選択制にする**。アクセシビリティとして解除可能に。
11. 本計画の行動分析は**個人を特定せず、オプトインで集計**する。
12. 「心理学の豆知識」はそのまま使わず検証する（CEDEC 2025 が注意喚起 [65]）。

## 4. 再現性・妥当性に議論のある知見（注記）

| 知見 | 状況 | 本計画での扱い |
|---|---|---|
| **自我消耗** | 大規模多施設追試で効果はほぼゼロ（d≈0.04）[15]。別の追試では小さな効果（d≈0.10）も報告され、課題の選び方に議論 | **使わない**（「疲れると選択が悪くなる」を仕組みにしない） |
| **選択のパラドックス／選択過多** | メタ分析で平均効果ほぼゼロ、ばらつき大 [25]。調整要因付きで効果が出るとの反論 [26] | 重要局面では絞る程度の控えめな使い方 |
| **損失回避（特に小さな損失）** | 一般性に論争 [22][23][24] | 「約2倍」の係数を仕組みに埋め込まない |
| **ツァイガルニク効果** | 普遍性は支持されにくい。再開傾向は一般的 [33] | 引きは「問い」で作る。効果に依存しない |
| **認知的不協和（強制承諾）** | 多施設追試で疑義 [36] | 補助的に留める |
| **特定可能な犠牲者効果** | 効果は報告されるが、熟慮との因果は研究間で不一致 [12] | 物語表現の指針に留める |
| **道徳基盤理論** | 多元性の主張に批判 [29] | ラベルを出さず参考に |
| **二重過程理論** | 2系統の厳密性に批判 [31] | 比喩として使う |
| **ピーク・エンド** | メタ分析で比較的強い支持 [10]。始まりと終わりが明確な経験に限る | 章構成に使う（章は区切りが明確） |
| **ミルグラム追試** | 条件・設計に批判 [52] | 場面設計の参考に留める |
| **juice** | 実験的根拠は今回未確認。過剰への反論 [57] | 控えめに |
