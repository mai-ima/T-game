### 2.4 時間制限つき選択（4つ）は緊張を生んでいるか

- 演出：直前に無線が5本重なり「答えは短く」と迫る構成は**緊張を作れている**【推測】。
- しかし仕組みが緊張を殺している：①時間切れは必ず慎重側（G）、②ヒント文が利害を明示、③選んだ結果が連携準備で決まるので、決断瞬間には「確かめる情報」が増えず、迷う意味が薄い、④45秒は台詞を読み終えて選ぶには長い。
- 改善：§5-1参照（時間切れを“決断しなかった”別展開にする、ヒントを削る、連携準備の“見込み”を提示して賭けにする、アクセシビリティ設定は維持）。

### 2.5 業務（ミニゲーム）の多様さと結びつき

駅ルートは find/sort/route/watch/memory/compose/checklist の7種を使い**多様性は十分**。問題は結びつき：

- 良い結びつき：放送文（compose）の出来が、規制後に無線で「放送、効いてます/届いてません」と回収される。waterの配布、連携の有無も回収される。
- 弱い結びつき：find「混雑前のホーム点検」は、見落とした危険が**夜に起きない**。sort「見物客の振り分け」「車いす動線」も、**夜に誰も困らない**。つまり業務が物語の“弾”にならず、評価値のみ。
- 非駅ルートの業務は**3種（sort/memory/checklist or compose）で、物語の山場と無関係**。基地ルートの「報告仕分け」で重く倒した報告（ブレーキの圧力戻り）が、後の「2号を出すか」の判断材料に**ならない**のは最大の機会損失（実際は2号が主題）【推測】。

### 2.6 台詞の質（引用は25字以内）

良い点：
- 「去年、迷子の男の子の帯を、三回結び直しました。」
- 「先に帰らせたのは、私だ。」
- 「消さない。あれがないと、今夜の数字は、決まらなかったから。」
- 動作モチーフ「手を横に振る」を全部署で回収する設計。

説明調（改善対象）：
- 「確定と見込みを分けてくれる人は、貴重。」（作品の主題を人物が宣言）
- 「聞いたことを、別の持ち場に渡す。そこまでが仕事だ。」（講義）
- 「止める判断は、恨まれる判断だ。」（総括の説教）
- 地の文：「体で分かった。」「判断は間違っていない。」（読者に感じさせる前に結論を言う）
- 同じ論点（確定/見込み）を浜口が全場面で言う → 繰り返しで印象が減る。

### 2.7 特につまらない箇所（第7章）

1. **指令ルートの前半（仕分け→暗唱→連絡文）**。「現場の声の仕分け」「運行表の暗唱」は、**自分の判断が誰かの運命に触れない作業**。20分間、事件も人物の欲望もない。
2. **計画ルートの前半**（暗唱、質問仕分け、説明資料）。これは会議資料の演習で、花火の夜の臨場感が全くない。
3. 全ルート共通の**引継ぎ（22:00）**：旗の朗読＋説教。選択の重みが「台詞が変わる」で終わる。

## 8. 心理学の倫理的適用（ダークパターンを避ける）

| 原理 | 現状の問題 | 倫理的な使い方 |
|---|---|---|
| **損失回避** | 失うものが描かれない | 選んだ側で**何を手放したか**を可視化する（規制した→広場の人の不満、通さなかった→ひなたの母の遅れ）。罰ではなく「代償」。やり直し課金や不安の煽りは禁止 |
| **後悔** | 「間違いじゃない」と語り手が免責 | **取り返せないが、取り戻せる余地**を残す（帽子を返す、謝りに行く）。後悔は次の行動で報われる形に |
| **自己決定理論**（自律・有能・関係） | 選択が無効化（自律）、努力が報われない（有能）、関係値が飾り（関係） | 自律＝選択が世界を変える／有能＝成績が**場面**として返る／関係＝**関係値を条件に使う** |
| **ピーク・エンド** | 各章の終わりが引継ぎ/面談で平坦 | 各章の**最も強い瞬間（小川、野村、2号）**の直後に締める。終幕は選択の余波を一場面で |
| **ツァイガルニク効果** | 秘密が回収されず放置 | 章末に**小さな未完の問い**を1つ残し、次章冒頭で必ず回収する（ホラーや不安煽りではなく好奇心） |
| **サスペンス** | 結果が分からない緊張がない（ヒントで予告） | 観客が知っていて登場人物が知らない情報（ヒッチコックの爆弾）。例：2号の数値を先に見せる |
| **物語への没入** | 説明調・旗朗読・3D断絶 | 場面で見せる、固有名の物を使う（帽子・団扇・付箋・腕章） |
| **コミットメントと一貫性** | 章末の選択が保留に消える | 選んだ道を**以後の章が尊重**する。選択を覆す場合も理由を物語内で示す |
| **社会的比較** | 山科との比較が第9章1場面のみ | 山科・同期の**別ルートの結果を、断片で見せる**（優劣を煽らず、違う道の存在を示す） |

禁止事項：不安を煽る時間制限の強制、課金や連続プレイ報酬による引き留め、選択をやり直させない罰、他者との劣等感の煽り。時間制限は既存の設定（無効化）を**必ず維持**する。

## 9. 具体的な作り直し案

### 9-1 第7章 時限選択（全4ルート）

- **時間切れ専用の展開 `ch7.hesitated` を作る。** 白石（基地なら橘、指令なら浜口）が「遅い。私が決める」と介入し、**どちらの案も“半端に”実行**される。小さな混乱（階段の女性、2号の再試験が中途）が起きる。罰ではなく「決断しないことも選択」。
- **ヒント文を削除**し、「一人ずつ止める／止めない」だけにする。結果の予告は、事前の連携先の台詞に埋める（既に良い）。
- **連携先の“見込み”を決断直前に表示**：「指令：止めれば後続は2分遅れ」「警備：広場は持つ」。プレイヤーの準備が**賭けの材料**になる。
- 粗い側の結果に**実害**を足す：規制→小川の娘は無事だが列の端で転倒者1名（軽傷・ベンチで手当）、誘導→階段で泣く子を抱えた母が押される。**語り手の免責（「判断は間違っていない」）を削除**し、人物が重みを言う。
- `limited/flowed` に「どう判断したか」を**1つの具体的な出来事**にして、第8章以降が拾う（§9-8）。

### 9-2 第7章 警備・売店・車掌の選択

- 売店 `clear/water`：**どちらを選んでも夜に必ず描く**。clear→通路が空いて車いすの方が止まらず通れる場面（`wheel` 業務の成績と連動）。water→広場のおじいさんが倒れず「冷たい」と礼を言う。**旗を読む場面を最低1つずつ**。
- 警備 `stairs/plaza`：階段側を厚くすれば階段は止まるが広場で人が倒れる、広場側なら逆。**どちらも小さな損が出る**。筒井の台詞を選択直後と夜で変える。
- 車掌 `rear/lead/leave`：`leave` を選ぶと夜に水城が**ベルの音で固まる**一瞬を描き、プレイヤーが声をかけて救うか見送るか（水城の苦手の回収）。
- `open_focus`（守りたいもの）：結果ゼロの選択を削るか、**夜の最後の評価の基準**として読む（守りたいものが守れたか）。

### 9-3 第7章 非駅ルートの前半を事件に置き換える

- **基地**：序盤の仕分けで**プレイヤーが重く倒した報告（2号のブレーキ圧）が、20:15の判断の材料**になる。倒さなかったら、橘の「どうして報告しなかった」。
- **指令**：序盤の仕分けの1件（「人が多い気がする」＝数字なし）を、夜に**本当に危険だった前兆**として回収する（確認の電話を選んだかで、規制が早いか遅いかが変わる）。
- **計画**：会議で後回しにした懸念（4つから3つ）が、**現場の事故未遂として夜に現れる**。作らなかった資料が、誰かを困らせる。
- 全ルート：序盤から20分以内に**小さな事件**（迷子、停電、落とし物の不審物疑い）を1つ入れる。

### 9-4 第8章 野村の場面（4ルート共通型の解体）

- **ルートごとに“選択の形”を変える**：駅＝時間の競合（今の形）、基地＝本人が止められるのを嫌がる（OBの誇り。止めるか敬意を払うか）、指令＝電話しか手段がない（誰に頼むか）、計画＝**補聴器に気づくタイミング**（質問を拾えるか）。
- **keep の代償を重くする**：帽子を返す機会が**次の章の冒頭に必ず来て**、返すと野村が本音を話す／返さないと梶原が代わりに返す。
- **pause の代償を変える**：行事を短縮する代わりに**若林や子どもの“好感”が上がる**など、有能感と関係の両面を返す。
- 第8章 `af_tour` の矛盾（事実L）を修正：`s_hi_choice` の選択で台詞を分岐。
- 「声を拾う」標語は**駅長1人にのみ言わせる**。他の人物は行動で見せる。

### 9-5 第9章 回想・面談の作り直し

- **手帳の頁を“場面”にする**：6頁のうち**2頁だけ**を選ばれた過去として**短い回想場面**（5〜8行、付箋の色、相手の台詞、プレイヤーの一言）で演じる。残りは付箋の一行に圧縮する。
- **面談を“対立”に**：評価者が**一つだけ厳しい指摘**をし、プレイヤーが**反論するか受け止めるか**を選ぶ。評価語は値で決めず、**場面で出た態度**で決める。
- **「評価の紙」を物にする**：評価値を台詞で読むのでなく、紙に**付箋が1枚増える/剥がれる**などの視覚で見せる。
- **自己評価 compose の選択肢順をシャッフル**し、“正解が先頭”を解消。さらに「正直だが不利な書き方／体裁の良い嘘」の**倫理的な選択**にする。
- `rd_choice`（傷との向き合い）は、選んだ方法で**後の章の人事の態度が変わる**旗を作り、第10章冒頭の事前メモで1行以上読む。

### 9-6 第10章 冒頭・面談・章末選択

- 事前メモの朗読（m1〜m6）を**1場面**（封筒を開く、付箋のように1〜2行だけ）に圧縮。残りの旗は、**実習中に出会う人が自然に言及**する。
- 異動可否面談（`jd_*`）を**数字の読み上げから、実習先の指導者が口頭で伝える短い会話**に置換。
- **章末選択を結果のある選択にする**：
  - `stay`：星野/橘/浜口/戸田が「持ち帰り課題」を出し、第11章冒頭で**駅に持ち帰ったものの成否**が最初のイベントになる。
  - `transfer`：「要件未達で保留」では終わらず、**条件を3つ提示**（在籍月数、研修、評価値）し、各条件が**第11章以降のどの場面で積めるか**を示す。保留でも**選んだ道に紐づく次章の事件**が始まる。
  - どちらも「同じ重さです」と言わない。**代償を述べる**（stay＝同期が先に進む／transfer＝慣れた人と離れる）。
- 3日目の課題成績を**実習先の最終の一言**だけでなく、**実際の持ち帰り物（資料、手順メモ、腕章）に反映**させる。

### 9-7 登場人物の継続

- **最小限の再登場**を各章に挿入：筒井（年末の初詣で駅に来る）、水城（ひなたの母を見た）、小川（娘の定期を持って礼に来る）。

- **ひなた**を第9・10章にも**団扇・写真・手紙**として出す（第10章冒頭に手紙1通）。

### 9-8 世界に残る“選択の痕跡”（Detroit的な可視化の応用）

- 第7章の判断を、**駅の掲示板・日報・手帳に残る“事実”**にする：「8/14 入場規制を実施」→ 第8・9・10章で**他人がそれに言及**（梶原が「あの夜の規制のおかげで孫が無事」/ 苦情のはがき）。
- **章フローチャート（StoryMap）**に、第7〜10章の重要選択を**“影響の線”**で表示し、「この選択は第9章のこの場面を変えた」と**章終了後に可視化**（既存実装を拡張）。ネタバレ防止のため章終了後のみ。

### 9-9 キャラクター・設定の整合性（先に直す）
