# DESIGN_PRINCIPLES — 分岐と体験の設計原則（RRR-DESIGN-001）

根拠：`docs/research/*.md`（Detroit／分岐設計論／心理学／日本の脚本技法／映像・UI）と `docs/analysis/*.md`（自作の実測）。
心理学の知見は仮説であり、プレイテストで検証する。ダークパターン（ガチャ的報酬、ストリーク、サンクコストによる離脱妨害、社会的比較）は使わない。

## 1. 診断（実測・事実）
- 関係値（rel）を条件に読む場面が R7 全体で0件。255回加減されるが物語は変わらない。
- 立てるフラグの約半数は一度も読まれない（R7第7〜10章は161個中82個）。
- 重要選択の約82%が3ノード以内に合流する。第1章の小さな依頼は「模範／平凡／危険」の同型3択で、直後に採点講評が付く。
- 第4章以降は会話中心で3D歩行がほぼ無い。時限選択はR7全体で5個。
- 伏線が回収されない（杉浦・津村・桐生・橘の秘密・母との約束・推薦枠）。人物ID `sawada` が二重定義。
- 2D背景は3種のみで時間帯が出ない。立ち絵は無表情が約72%。章末は数値の羅列。

## 2. 原則（作る側が守る）
1. **選択は代償を伴う**：どの選択肢にも守る価値と失うものがある。「報告すれば確実に得」は選択ではない。損失は抽象値でなく具体物（人・約束・機会）で示す。
2. **必ず後で読む**：フラグを立てる選択は、読む側のノードID（payoff）を持つ。読まれないフラグは作らない（品質ゲートで機械検査）。
3. **合流を遅らせる**：重要選択から合流点まで4ノード以上、または合流後も人物の「記憶」で台詞が変わる。章をまたぐ選択は少なくとも3章先まで効く。
4. **取り返しのつかない変化を暴力なしで作る**：異動の確定／不成立、同僚の離職、師弟の決裂、信頼の喪失、事故報告の結果、資格の取りこぼし。`depart`（退場）と `lock`（恒久閉鎖）で表現する。
5. **関係値を物語に効かせる**：rel を条件にする場面を各章2つ以上。数値は画面に出さず、人物の態度・台詞・呼び方・頼みごとで見せる。
6. **選択直後に採点しない**：正誤の講評を即時に出さない。反応は人物の表情と、後の章での扱いで返す。評価点より「失ったもの／得たもの」を章末で見せる。
7. **沈黙も選択**：時限選択の時間切れは「何も言わない」を既定にし、結果を残す（アクセシビリティ設定で時限は解除可能）。
8. **主人公と他者の目標がぶつかる**：人物ごとに「欲しいもの」と「隠していること」を持たせ、台詞で主題を説明しない（場面に遅く入って早く出る、感情の爆発は章に最大1回）。
9. **業務は物語に接続する**：業務の結果が、人物・時間・情報として後に響く。点検文が答えを言わない。失敗しても進み、代償が付く。形式を連続させない。
10. **歩く・調べるを戻す**：第4章以降も3D歩行／調査の場面を各章に入れる（券売機室、ロッカー、張り込み等）。
11. **章は山場1つ＋余韻**（ピーク・エンド）。章末は問いを1つ残し、選ばなかった道（ロック表示）を見せる。
12. **見た目は文脈に合わせる**：2D場面は時刻（朝・昼・夕・夜）で色味を変え、立ち絵は呼吸・まばたき・口パクで生きている感じにする。強い演出は重要選択のみ。動きは `prefers-reduced-motion` で止まる。

## 3. 測定目標（品質ゲート `tests/narrative-quality.test.ts` の TARGET）
| 指標 | 現状 R7 | 目標 |
|---|---|---|
| 読まれない選択肢（dead） | 34% | ≤10% |
| 3ノード以内合流の重要選択 | 82% | ≤25% |
| 一度も読まれないフラグ | 55% | ≤15% |
| 時限選択 | 5 | ≥12 |
| rel を読む条件 | 0 | 章あたり≥2 |
上限（CEILING）は改善のたびに下げ、上げない。

## 4. 実装順
1. エンジン：`depart`（退場）・`lock` 効果、`gone`/`locked` 条件、lint で「読まれないフラグ」「読まれない rel」警告。
2. 横断：人物の記憶（`remember`）で台詞差分、選択直後の採点講評の撤去。
3. 章ごとに story-architect で重要選択をジレンマへ書き直し（第1→10章の順、各章でゲートを下げる）。
4. 伏線の回収（杉浦・津村・桐生・橘・母・推薦枠）、`sawada` 重複の解消。
5. 演出：P1（時限選択のリング、章タイトルカード、天候）、P2（章末の感情的な振り返り、背景の時間帯バリエーション）。
